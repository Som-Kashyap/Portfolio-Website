# Portfolio

This is my portfolio webpage built using HTML and CSS, featuring About, Skills, Projects, DSA and Contact.  
It showcases the projects that i've worked on, with clear Tech Stack, brief description, Gifs / Screenshots for getting overview, and clickable Github repsitory link.

## Features

- About Section: A brief introduction of me and my department, the current and future goals and the domains i've covered
- Skills Section: Displays the skills that i've acquired so-far
- Projects Section: Showcases the projects that i've worked on, with card-like layout that contains Tech Stack, Description, project Gif for overview and Github repository link
- DSA section: Statistics of my DSA journey on LeetCode and, list of topics that i've covered
- Contact section / footer: Contains Email and links to my socials
